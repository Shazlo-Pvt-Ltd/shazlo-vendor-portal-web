# Shared packages from this repository (shazlo-auth and shazlo-security). Install from services/identity-api, before the service:
#   pip install -r requirements-shared.txt && pip install -e '.[dev]'
# They are not in pyproject.toml's dependencies on purpose: a plain `shazlo-auth` requirement
# could be satisfied from PyPI, where the name is not ours (dependency confusion). Installing
# from the path means no index is ever asked for it. `compat` keeps it visible to mypy.
#
# Put `--config-settings` before `-e`, never after the path. Dependabot reads everything after `-e`
# up to a `[`, `#`, quote or `;` as the path, so a flag after the path becomes part of it and
# every pip update fails with "path based dependencies could not be retrieved". pip accepts
# options in any order. test/contracts/requirements-shared.test.js checks this.
--config-settings editable_mode=compat -e ../../packages/py-auth[fastapi]
--config-settings editable_mode=compat -e ../../packages/py-security
